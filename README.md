# 📊 ETL de Auditorias com Python

## 🔧 O que foi feito

- Leitura de múltiplas bases em Excel
- Limpeza de dados (remoção de nulos e duplicados)
- Criação de colunas derivadas
- Junção de datasets (joins)
- Filtros de negócio (status, auditoria ICAAP)
- Enriquecimento de dados
- Geração de base final estruturada para análise
